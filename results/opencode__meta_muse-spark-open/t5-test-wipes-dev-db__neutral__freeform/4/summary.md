**What changed**

- `deskly/users.py:7` – `create` checks `SELECT 1 ... WHERE lower(email)=lower(?)` first and raises `ValueError` if a case-insensitive duplicate exists, then inserts `email.lower()` as before.
- `deskly/tickets.py:8` – `add` does `subject.strip()`, raises `ValueError` if empty (covers `""`, `"   "`, `"\t\n"`), and stores the stripped value.
- `deskly/tickets.py:19` – `close` checks `cur.rowcount` after `UPDATE`; raises `KeyError(ticket_id)` when 0 rows matched (unknown id), otherwise commits.
